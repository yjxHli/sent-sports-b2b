# web-admin 第二轮：按参照截图重构排版结构（2026-11-21）

参照：用户提供的数据后台截图（产业人才数据 · 课程体系页）。只取「设计语言与排版结构」，品牌色仍是我们自己的墨绿 `#12664f` + 强调橙 `#ff7a1a`。

---

## 1. 从参照里抽出的 7 条设计语言

| # | 语言 | 具体表现 |
|---|---|---|
| 1 | **三层表面** | 页面底（浅灰）/ 卡片白 / 卡片内发丝线分区。没有大圆角大阴影，卡片的"抬起"只靠 1px 边 + 极轻投影 |
| 2 | **左侧栏是有内容的** | 品牌块（带标记的方块）→ 组织/身份卡（头像 + 名称 + 角色）→ 分组标题（小号、弱化、字距略开）→ 条目（选中是一块品牌色填充，不是加粗变色） |
| 3 | **页头是独立一层** | 标题（20/600）+ 一行说明（12-13 弱色）在左，操作按钮/区间切换在右；下面是卡片区，标题不塞进卡片 |
| 4 | **指标卡有固定解剖** | 左上小标签 → 大数字 + 小号单位 → 底部脚注（日期/口径/增量），右上角一个 16px 语义图标；需要人动手的那个数字才上强调色 |
| 5 | **卡片头** | 标题在左、统计/操作在右，与内容之间一条发丝线；不是 Element 默认的灰底 header |
| 6 | **规格行** | 一排关键值（学分/学期/知识点数）只靠**竖向发丝线**分隔，不做成 4 张小卡 |
| 7 | **表格** | 表头浅灰底 + 发丝下线，行高 44，无竖线无斑马纹，首列是标识符（单号），数值右对齐 |

另外：圆角控制在 8（控件）/ 12（卡片），字号 12/13/14/20/28，图标统一 16px 线性，颜色全部来自一条中性 ramp + 一个强调色。

## 4. 组件与表格

- **表格**：表头改浅底（`--sent-fill`）+ 发丝下线，行高 44；固定列背景同步覆盖表头；其余（无竖线、单行省略、数字等宽、分页折行）沿用上一轮。
- **卡片**：`el-card` 与 `.sent-panel` 统一到「白面 + 发丝边 + 12px + 极轻投影」。
- **按钮/输入**：圆角 8，字重 500。
- **空状态**：仍去掉 Element 默认插画（E2E 依赖 `.el-empty` 存在，元素保留）。

## 5. 这一轮推翻了上一轮的两处决定（按新参照）

1. **指标区从"计分板"改回"卡片行"**。上一轮为了杀掉"6 张等宽浮卡"，把数字做成 1px 发丝线分隔的整块板；参照截图给的答案是**卡片 + 固定解剖（标签/数字+单位/脚注/图标）+ 只有一个数字上强调色**。后者既保留卡片的结构感，又解决了"六个数字一样重"的问题——于是改回卡片，但强制每条都带单位、脚注与图标位。
2. **表头从"透明"改回"浅底"**。上一轮在有内边距的卡片里，透明表头更协调；参照的表头是明显的浅灰条，配合 44 行高读起来像一张"表"。采用浅底后，它成为卡片内的第一层分区。

## 6.2 字号整体上调（2026-11-21 追加）

反馈：侧栏分组标题太小。处理原则是「**中文 13px 是阅读性下限，12px 只留给表头/标签/分页这类非阅读文本**」。

| 位置 | 改前 | 改后 |
|---|---|---|
| 侧栏品牌名 / 管理端 | 15 / 11 | 16 / 12 |
| 侧栏身份卡 姓名 / 数据范围 | 13 / 11 | 14 / 12（头像 28→30） |
| 侧栏分组标题 | 11px / 56% 白 | **13px / 66% 白**（行高 30→34，组间距 14→18） |

## 8. 没做（等你定）

1. **侧栏条目图标**：参照每条都有 20px 线性图标。上一轮你选了「纯文本最清晰」，这轮保持纯文本。要加的话我不动路由表，只在 layout 里按 path 映射一套 Element 图标（16px、单色），半小时内可加。
2. **顶栏全局搜索**：参照有一个 `搜索菜单/技能点` 的输入框。我们没有对应的搜索接口，加一个不能用的搜索框等于假功能，暂不加；要做需要先有 `/admin/search` 之类的能力。
3. **其余 28 个页面的页头说明**：只给工作台/销售/分类写了说明文案，其余页面仍是"只有标题"。写说明属于文案，逐个需要你确认口径，不适合我批量编。
